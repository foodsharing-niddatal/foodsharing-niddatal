# foodsharing Niddatal e.V. – Website

Statische Website (HTML/CSS, kein Build, keine Cookies, keine externen Schriften) für **foodsharing-niddatal.de**.

- `docs/` ist der Webroot (GitHub Pages: Branch `main`, Ordner `/docs`)
- Inhalte stehen direkt in `docs/index.html`, Impressum und Datenschutz in den gleichnamigen Dateien
- `qr/` enthält die QR-Codes (Landingpage, Mailto Partnerbetrieb)
- Logo und Marke: foodsharing-Netzwerk, Nutzung mit dessen Genehmigung

Stand: Entwurf, Texte vor Veröffentlichung vom Vorstand prüfen lassen.
